# cui.symbols

40 枚原创静态图标，图形数据全部保存在仓颉源码。各图标是独立子包，父包没有资源总表、注册表或再导出。
完整用法和链接边界见[预置图标指南](../../../guide/how-to/preset-icons.md)。
