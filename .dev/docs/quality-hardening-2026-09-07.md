# 2026-09-07 质量加固与滚动边界回归

本轮从 planner 双页最后一张卡片的底边框缺失出发，检视了布局尺寸、绘制裁剪、几何缓存、滚轮路由与原生资源状态；字体、文本编辑、启动、后台投递、模态焦点和关闭流程沿用并重跑既有回归。没有改变应用公开接口。SDL 原生构造默认可见的契约保留，三个原生示例显式选择隐藏首帧流程。

## 已确认并修复

| 问题 | 原因与处理 | 验证 |
|---|---|---|
| SDL 原生示例启动黑屏／白块 | 三个示例的构造直接显示窗口，资源与首帧随后准备；入口改为隐藏创建，完整首帧提交后显示并立即重绘，游戏计时从准备结束后开始 | calculator 修复前原生可见性断言失败；三个示例分别验证直接／超采样建窗与首帧路径 |
| planner 底边框缺失 | SDL 裁剪把坐标和宽高分别截断，合计可能丢失接近两个逻辑像素；改为对交集四条边向外取整，空交集保持为空 | 修复前 8 组底／右边像素对照全部失败；实际 planner 两页增加独立底线像素断言 |
| 小数尺寸绘制受历史顺序影响 | 四分之一像素缓存键复用了首个尺寸的真实网格；改用尺寸浮点位模式作为键，保留两代容量与复杂度限制 | 圆角填充／描边、圆形填充／描边分别比较冷缓存与相邻尺寸预热后的实际 GPU 输出 |
| 原生裁剪失败污染逻辑状态 | 原先先入栈再调用 SDL；现在设置／恢复成功后才提交逻辑栈，拒绝无法表示的有效矩形 | 超范围失败后，逻辑裁剪和 SDL 裁剪保持原值，随后可正常弹栈 |
| 外层抢先滚动、内层到边界后吞事件 | ScrollView 与 Lazy 系列先路由子项；列表、表格、树和文本区只在实际偏移改变时消费 | 8 类控件分别验证内层先滚、到边界后外层接续；忽略零／非有限滚轮增量 |
| 右键误触滚动条、极小视口滑块溢出 | 普通／虚拟视口的滚动条只处理主键；横纵最小滑块尺寸同时受实际轨道限制 | 右键无滚动／捕获，横纵极小轨道几何断言及原生输入场景 |

planner 的内容高度与滚动范围计算没有发现少算尾项。本次未增加示例补偿留白。

## 裁剪约束与发布范围

SDL 的裁剪接口只接收整数逻辑矩形，因此本轮采用保守覆盖，每边最多扩张不到一个逻辑像素。原始逻辑命中、语义可见范围和嵌套交集保持不变；有意伸出卡片边界的阴影仍需按设计留白。

本轮验证平台为 Windows 与仓颉 1.0.5。既有 Linux／macOS 实机、屏幕阅读器、长期资源、安装包和签名验收仍在 todo 中；本轮结果不能代替这些发布验收。
