# 静态图像组件升级与验证（2026-09-09）

后续的缓存、原生状态、异常隔离与文件写入加固，以及最新验收结果，见[图像链路复核与加固](image-hardening-2026-09-09.md)。

本次扩展 CangjieSDL 与 CangjieGUI 的静态图像链路，原生环境为 Windows x64、仓颉 1.0.5、SDL 3.4.12、SDL3_image 3.4.6。未引入动画播放。WebP、TIFF、AVIF 的可选 DLL 未放入运行时目录，也没有作为默认交付依赖。

## 已交付能力

- CangjieSDL：文件及编码内存解码、按尺寸栅格化 SVG、位图等比缩小、像素预算、Surface 尺寸/读像素/缩放、PNG/JPEG 保存，以及带圆角、颜色、透明度、镜像与采样选项的纹理绘制。
- CangjieGUI：复用文件或不可变内存来源；Contain/Cover/Stretch/Original/ScaleDown 五种适配；九向对齐、源区域裁剪、独立布局与解码尺寸、自定义解码预算、背景、边框、圆角、透明度、着色、镜像、采样、备用图、错误占位、加载诊断和可访问性说明。
- 资源与刷新：沿用线程/渲染器归属和有界缓存，尺寸变体拥有独立缓存键；支持同步预热。文件更新后使保留绘制失效；原图尺寸参与测量时，同步使布局失效。关闭视图不销毁其他视图共享的纹理。
- 示例：新增“图像工作室”，扩展 calendar 使用 PNG 和链式尺寸/样式接口；提供原创图像和可重新生成的解码夹具。构建、暂存和跨平台 CI 的运行时依赖加入 SDL3_image。

实测解码覆盖 BMP、PNG、JPEG、GIF 静态图、SVG、QOI、TGA、ICO、PNM 中的 PPM、PCX、XPM；同时测试混合大小写后缀、非图像后缀、内存输入、透明像素、坏文件与失败后的恢复。其余格式取决于 SDL_image 实际编译的解码器；没有把可选解码器的声明当作本机已支持能力。

## 使用与实现说明

完整用法见[静态图像指南](../../docs/guide/how-to/images.md)、[ImageView API](../../docs/api/cui/media/ImageView.md)与[图像工作室](../../examples/images/README.md)。指南说明了参考 Qt Quick、Flutter、WinUI 的具体设计取舍。

旧 ImageView 文件构造和首选尺寸参数仍可使用；常见调用使用 size、decodeSize、fit、cornerRadius、alt。decodeOptions 可传入完整 ImageLoadOptions，与 preloadImage 使用相同参数即可复用预热结果。

修复与防护覆盖：混合大小写扩展名、失败缓存诊断、缓存键隔离、共享纹理样式污染、采样状态恢复、解码/上传失败资源清理、保留绘制刷新、原图尺寸变更后的重新测量，以及背景/边框抗锯齿边缘的重绘范围。

## 性能

保留纹理缓存和失败缓存；样式修改不复制纹理，圆角网格有界缓存并复用原生顶点缓冲区。Cover 以源区域取样替代逐图切换裁剪状态。

以 HEAD 旧 ImageView 绘制逻辑作为对照，在隔离副本中与新实现共享当前缓存后端、同一进程交替测试。原生窗口网格含 100 张图片，400×240 逻辑尺寸，1× 超采样；每组 50 帧，7 组。计时包含场景开始/结束及 100 次 Widget.draw，不含 DesktopApp 的事件、布局调度、窗口呈现等待和保留场景的空闲帧：

| 场景 | 旧实现 | 新实现 |
|---|---:|---:|
| Contain 网格 | 52.484 μs | 50.490 μs |
| Cover 网格 | 108.472 μs | 50.498 μs |

另有 45 次交替的无头负缓存微基准：稳定视图中位数 6 → 8 ns，新建视图中位数 62 → 65 ns。这反映新增状态观察/分支存在微小成本，不能宣称严格零开销。新增实现最初的多余调用已做针对性收敛；上述直接绘制场景未观察到退化，Cover 有明显改善。测试时后台仍有示例编译，结果是本机证据，不代表所有 GPU、负载或平台的绝对性能保证。对照源码与原始日志位于 target/dev/image-upgrade/perf-compare 和 compare-grid-timings.log。

## 使用边界

首次加载与预热为同步操作；默认测量不访问磁盘，intrinsicSize 显式允许加载。位图的 decodeSize 在完整解码后缩小，降低驻留纹理成本但不能约束解码器临时内存；maxPixels 检查解码结果。SVG 使用 SDL_image 的静态子集，GIF 不播放动画。网络来源、动画调度及额外可选解码器未纳入本轮。

本机验证覆盖 Windows x64。Linux/macOS 的构建配置和依赖门禁已更新，尚未在相应目标机器运行，因此不声称完成跨平台原生验收。
